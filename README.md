# WDPG-AGENT Supporting Materials

This repository provides supporting materials for the WDPG-AGENT manuscript, including method configuration files, prompt materials, knowledge-graph schema, prescription-library summaries, and evaluation protocols.

The materials are intended to support method inspection and reproducibility of the documented study workflow.

## Included

- Optimized diagnostic prompt.
- Retrieval and inference configuration.
- Knowledge-graph schema, extraction prompt template, normalization rules, and Cypher templates.
- Prescription-library summary and representative examples.
- De-identified expert-review protocol and summary.
- Dataset split summary.
- Data split, evaluation, expert review, DSPy prompt optimization, and knowledge-graph reconstruction protocols.

## Dataset Access

The datasets are not publicly available at this stage because the related research project is still ongoing. Requests to access the datasets should be directed to the corresponding author(s).

Private credentials, local service settings, expert-identifying records, and database dumps are not part of this public repository.
